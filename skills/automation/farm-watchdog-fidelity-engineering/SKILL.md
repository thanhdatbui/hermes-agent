# Farm Watchdog & Reporting Fidelity Engineering

## 1. When to Use
Use when creating, auditing, modifying, or troubleshooting background watchdogs, scheduled cron reports, and alert aggregators on automation farms.
Applies whenever reports fail to reflect actual fleet health, mask dropped machines, report false aggregate metrics, or omit actionable failure details.
Also applies when compliance reports trigger high failure counts and agents enter a block death spiral due to misaligned guidance or false-positive subfolder blocks.

## 2. Core Invariants Summary & Deep References
- **4-Way Multi-Tier Cron Sync Parity & Canonical Forwarding Shim (Anti-Ghost Revert / Stale Runtime):** Khắc phục triệt để hiện tượng sửa code trong Git Repo nhưng Cron Scheduler vẫn chạy code cũ từ `%LOCALAPPDATA%` hoặc bị OneDrive đè ngược. Kiến trúc tối ưu: Sử dụng **Canonical Zero-Drift Forwarding Shim** (~40 dòng kẹp `-B` cấm bytecode cache và `creationflags=0x08000000`) tại Runtime/Deploy/OneDrive để trỏ thẳng về Git Repo nguồn (`D:\Taadaa\...\scripts\`). Mọi thay đổi trong Git có hiệu lực tức thì 100% không cần copy. Với script thường chưa gắn shim, bắt buộc tuân thủ quy trình 4-Way đối soát SHA-256 kèm `cron_sync_watchdog.py --force`. Chi tiết: [`references/four-way-cron-sync-parity-and-runtime-drift.md`](references/four-way-cron-sync-parity-and-runtime-drift.md).
- **Watchdog Session 1 Baseline Buffer Parity (Anti-Zero-Buffer T0 Trap):** Trong watchdog đối soát delta (như follow/upload), cửa sổ truy vấn baseline T0 cho Phiên 1 (`is_p1_or_unknown`) bắt buộc phải có buffer tối thiểu 15 phút (`buffer_reconcile_iso(session_start_iso, 15)`). Cấm tuyệt đối gán 0 buffer vì tiến trình cào T0 đầu phiên chạy mất 1–2 phút sau mốc bắt đầu ca, khiến SQL query `timestamp <= session_start_iso` loại bỏ snapshot T0 tươi mới và rơi vào bẫy stale baseline > 4h dán nhãn `UNPROVEN`. Chi tiết: [`references/watchdog-p1-zero-buffer-t0-exclusion-trap.md`](references/watchdog-p1-zero-buffer-t0-exclusion-trap.md).
- **Cronjob Guard Guidance, Auto-Rewire & Farm Contract Templates (Anti-Block Death Spiral):** Khi nhận báo cáo Gate G8/G7 nổ vi phạm hàng loạt, phân định dứt khoát: Tầng Auto-Rewire tự động tiêm ngầm 0-turn `no_agent=True` khi lệnh đã có `script` (thỏa 3 Tiêu Chí Vàng: tất định, thu hẹp quyền hạn, minh bạch); Tầng Active Pivot (Fail-Fast) bắt buộc trả về pre-filled `farm_contract` template chuẩn (touches_device=false vs rolling 1..50) và context-aware guidance tra cứu file O(1), triệt tiêu bão thử sai mò mẫm. Chi tiết: [`references/cronjob-guard-guidance-auto-rewire-and-contract-templates.md`](references/cronjob-guard-guidance-auto-rewire-and-contract-templates.md).
- **Cron Guard Single-Pass Active Pivot & Pipeline Execution Invariant:** Khi cron watchdog báo vi phạm hàng loạt ở G8, hook `guard_cronjob_safety.py` bắt buộc tiêm metadata `auto_rewire` với `strategy: "single_pass_active_pivot"` + `stop_retrying_original_payload: True`. Đặc biệt: khi User ra lệnh nắn/sửa, Coordinator BẮT BUỘC kích hoạt NGAY TRỌN GÓI Gate A-Z (`unified_patch_pipeline.py run`), cấm đứng im giải trình phương án xin duyệt gây bại liệt flow. Chi tiết: [`references/cron-guard-single-pass-active-pivot-and-prefilled-contract-invariants.md`](references/cron-guard-single-pass-active-pivot-and-prefilled-contract-invariants.md).
- **Closeout Gate Timeout In Dirty Repos & Mandatory Target Scoping:** Trong các repo tồn đọng file dirty, gọi `closeout_gate.py` trần sẽ gom toàn bộ test files và vượt ngưỡng cứng `timeout=30`, gây FAIL oan. BẮT BUỘC truyền rõ `--target-file <file>` để cô lập focused test suite duy nhất của file mục tiêu, đảm bảo thời gian chạy < 30s. Chi tiết: [`references/closeout-gate-dirty-repo-test-timeout-and-target-scoping.md`](references/closeout-gate-dirty-repo-test-timeout-and-target-scoping.md).
- **Cron Auto-Quarantine (Missing no_agent=True) & Telegram Stale Thread Delivery Drift:** Các batch/automation scripts nặng (Playwright, GPM, account rescue) chạy quá 180s nếu để LLM Agent làm wrapper (`no_agent=False`) sẽ liên tục dính timeout error và bị đưa vào `AUTO_QUARANTINE`. Bắt buộc chuẩn hóa `no_agent=True` kèm `script`. Đồng thời, các cron job báo cáo định kỳ phải xóa bỏ `thread_id` rác của các topic Telegram đã đóng để tránh warning `thread_id not found`. Chi tiết: [`references/cron-quarantine-no-agent-and-telegram-stale-thread-drift.md`](references/cron-quarantine-no-agent-and-telegram-stale-thread-drift.md).
- **Canonical Forwarding Shim & Pre-Push Hook Closeout Receipt Binding:** Tránh LLM timeout trên job nặng bằng Canonical Forwarding Shim (`no_agent=True` + `python -B`). Đồng thời khi push code farm, lệnh `safe_push.py` bắt buộc phải có biên lai `closeout_gate.py --base HEAD~1` (hoặc `closeout_v2.py --base HEAD~1`) cho đúng commit `HEAD` trước khi push để vượt pre-push hook. Chi tiết: [`references/cron-forwarding-shim-and-pre-push-receipt-binding.md`](references/cron-forwarding-shim-and-pre-push-receipt-binding.md).
- **Passive SQLite Call Logs Audit vs Active Probe Over-engineering (AI Pool Watchdog):** Chống over-engineering khi giám sát pool LLM upstream (Gemini Pro / Claude pool). Thay vì chạy active probe lặp từng acc bắn request ra ngoài gây tốn quota và nguy cơ 429, giải pháp O(1) tối ưu là query thụ động bảng `call_logs` trong `storage.sqlite` với cửa sổ 3 ngày (72h). Acc có 0 req 200 OK mới probe nhẹ 1 token để phân loại: `BLOCKED` (403 VALIDATION_REQUIRED/QR), `DEAD/DOWNGRADED` (rớt free-tier/tắt), hoặc `STARVED` (bị đói tải do thuật toán least-used). Chi tiết: [`references/passive-sqlite-call-logs-audit-vs-active-probe-overengineering.md`](references/passive-sqlite-call-logs-audit-vs-active-probe-overengineering.md).
- **Post-Upload Audit Empty Schema & Watchdog Silence (Anti-KeyError Crash):** Khắc phục lỗi crash `KeyError: 'date'` và nổ alert giả khi watchdog đối soát sau ca (`post-upload-auto-audit-sync`) chạy vào khung rạng sáng (00:45) lúc chưa có nick nào upload. Bắt buộc chuẩn hóa schema parity khi `not accounts` và giữ stdout rỗng để kích hoạt tính năng Watchdog Silence của Hermes cron. Chi tiết: [`references/post-upload-audit-empty-schema-and-watchdog-silence.md`](references/post-upload-audit-empty-schema-and-watchdog-silence.md).
