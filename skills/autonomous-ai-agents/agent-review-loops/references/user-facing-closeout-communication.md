# User-facing closeout communication

- Be direct and concise; do not narrate every background poll or repeat the same status.
- Report only verified facts: exact command, exit code, test summary, and reviewer score/verdict.
- Never say "xong", "an toàn", "DONE", or "APPROVED" when Closeout Gate is `REJECTED`, score is below 85, or the result is only a worker self-report.
- If the gate fails, state the concrete blocker and the next remediation action in one short update. Do not ask for permission for allowed remediation steps.
