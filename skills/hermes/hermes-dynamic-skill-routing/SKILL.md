# Hermes Dynamic Skill & Rule Routing O(1)

Use this skill when handling diverse farm tasks where loading all 190 skills at once causes context bloat, token bleeding, and summarization pruning (`[SKILL_PRUNED]`).

## Core Architecture

Instead of static full-loading of all skills into the session prompt:
1. **Catalog Index (`tools/skills_index.json`)**: Pre-built lightweight JSON index of all 190 skills generated by `tools/build_skill_index.py`.
2. **O(1) Keyword Matcher (`tools/skill_lookup.py`)**: Sub-second matching of task intent against skill names, categories, and descriptions.
3. **Core Invariants Guarantee**: Pinned core skills (`taadaa-farm-ops-rules`, `farm-anti-overengineering`, `session-close-protocol`, `evidence-first-delivery`, `agent-verification-loop`) are ALWAYS returned.
4. **Selective Loader (`tools/load_selected_skills.py`)**: Loads ONLY the matched skills into the active working context.

## Usage Commands

```bash
# 1. Search relevant skills for a task
python D:/Taadaa/tools/skill_lookup.py --query "wifi airplane mode"

# 2. Output as JSON for programmatic consumption
python D:/Taadaa/tools/skill_lookup.py --query "add 2fa" --json

# 3. Load selected skills into context block
python D:/Taadaa/tools/skill_lookup.py --query "tiktok follow" --json > tmp.json
python D:/Taadaa/tools/load_selected_skills.py --from-json tmp.json

# 4. Rebuild index after adding or updating skills
python D:/Taadaa/tools/build_skill_index.py --skills-dir D:/Taadaa/Hermes/skills --output D:/Taadaa/tools/skills_index.json
```

## Failure Modes & Safety Rules
- **No Match**: If query has no matching skills, returns `[NO_MATCH_FALLBACK]` with ONLY the pinned core invariants. NEVER fall back to full 190-skill dump.
- **Index Stale**: If `skills_index.json` is older than skill directories, `skill_lookup.py` emits `[INDEX_STALE]` warning on stderr. Run `build_skill_index.py` to refresh.
