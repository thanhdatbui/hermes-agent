# Bẫy Lệch Pha RAM & Mã Nguồn: Python Gateway Long-Running vs Runtime Sync

## 1. Hiện Tượng & Triệu Chứng
- Code vá lỗi mạng/tải ảnh đã được commit vào git và ghi vào file `.py` trên ổ cứng (ví dụ `_download_telegram_file_with_retry` trong adapter).
- Nhưng người dùng thử nghiệm thực tế vẫn bị văng lỗi cũ (như cảnh báo không tải được ảnh).
- **Nguyên nhân cốt lõi**: Tiến trình Daemon Gateway (`pythonw.exe -m hermes_cli.main gateway run`) là tiến trình chạy dài (long-running). Python chỉ load module vào RAM lúc import khi tiến trình khởi động. Nếu Gateway không được restart, toàn bộ sửa đổi trên đĩa hoàn toàn vô hiệu hóa trong RAM.

## 2. Bẫy Tử Huyệt Khi Restart: Bán Đồng Bộ `site-packages` (Partial Sync / Incomplete Dependency)
- Khi một agent thực hiện [L2-surgery] hoặc copy chắp vá vài module mới vào `site-packages` mà không đồng bộ các module phụ thuộc mới (ví dụ các module hủy lệnh như `AuxiliaryExplicitCancellation` hay `hermes_state_common`), tiến trình Gateway đang chạy trong RAM vẫn sống nhờ bytecode cũ.
- Khi người dùng hoặc script thực hiện restart Gateway, tiến trình mới import `site-packages` bị lệch pha và dính `ImportError`, rơi vào vòng lặp crash liên tục.
- **Quy tắc khắc phục chuẩn**:
  * Khi sync mã nguồn vào `site-packages`, BẮT BUỘC sync trọn vẹn toàn bộ cây runtime từ git HEAD (`agent`, `gateway`, `hermes_cli`, `tools`, `plugins`, `providers`, `cron`, và các module top-level).
  * Luôn tạo bản sao lưu thư mục `site-packages` trước khi sync (ví dụ `sitepkg_full_<date>`).

## 3. Khắc Phục Kẹt File Lock Mồ Côi Sau Crash
- Khi Gateway hoặc các agent nền bị kill/crash đột ngột giữa chừng, các file lock bảo vệ có thể bị giữ bởi các tiến trình con mồ côi hoặc handle chưa giải phóng trên Windows.
- Điều này kích hoạt cơ chế bảo vệ fail-closed của guard: không thể giành lock sau 3s và mọi tool call bị chặn đứng.
- **Lệnh dọn dẹp an toàn qua PowerShell**:
  Quét và dọn các tiến trình Python phụ/mồ côi không phải gateway hoặc dashboard, sau đó dọn file lock mồ côi trong AppData để khôi phục quyền điều phối.
