## Lessons Learned

1. **Absolute paths required** — `GetFileFromPathAsync` fails silently on relative paths
2. **`text=True` breaks on Windows** — use `.decode('utf-8', errors='replace')` instead
3. **Always write `.ps1` file + `-File`** — inline `-Command` has escape/backtick hell
4. **Fallback language** — `TryCreateFromUserProfileLanguages()` often returns null; use `TryCreateFromLanguage('en-US')`
5. **Upscale 3x with Pillow** — dramatically improves small/low-res text (as shown by popup crop)
6. **Vietnamese OCR** — en-US engine garbles Vietnamese diacritics; `vi-VN` language pack needed for accurate Vietnamese

## Language Pack Installation (if needed)

```powershell
# Check available
[Windows.Media.Ocr.OcrEngine]::AvailableRecognizerLanguages | ForEach-Object { $_.LanguageTag }

# Install vi-VN via Windows Settings > Time & Language > Language > Add a language > Vietnamese > Install OCR
# Or use DISM/PowerShell:
Add-WindowsCapability -Online -Name "Language.OCR~~~vi-VN~0.0.1.0"
```
